# Request Billing and Cache Writes

The official rate card now defines cache-write prices for GPT-5.6 and later
OpenAI families as well as Anthropic. The bundled table already contained these
rates, and the fallback calculation already applied the premium by rate rather
than provider. The Anthropic-only documentation was stale.

The installed extension's JSONL exporter includes `copilotUsageNanoAiu` when
present, including zero, but omits exact cache-creation token counts. Its network
and OTel code can carry `cache_creation_input_tokens`; absence in the exported
JSONL does not prove absence throughout VS Code. The built-in debug summary sums
`copilotUsageNanoAiu`. Converting that sum by `1e11` gives USD.

The investigation reproduced four package defects: skill buckets discarded billed
costs; any nonzero billed amount suppressed estimates for unbilled requests in the
same model bucket; explicit zero billing triggered estimation; and fallback tier
selection used aggregate tokens rather than each request's context. Versioned
model names could also match a broader pricing prefix before the specific variant.
Focused regressions verified the corresponding fixes.

After those fixes, 34 sessions with complete billing telemetry matched the recorded
billed amounts at the four-decimal USD output precision. Across inspected sessions,
model, subagent, and skill decomposition differed from session totals by at most
USD 0.00005, attributable to four- versus six-decimal rounding. Inspected non-utility
requests included GPT-6.1 Sol (724), GPT-6 Luna (858), GPT-5.6 Luna (1784), GPT-5.6
Terra (42), GPT-5.6 Sol (232), Claude Opus 5 (5), and a BYOK GLM model (31).
Some GPT requests and all inspected GLM requests lacked billing telemetry.

This supersedes the earlier Finding as guidance for current estimation, not as a
denial of its historical Claude-session measurement. Fresh input is not proof of
cache creation. Without billed telemetry, token-only costs remain estimates;
unknown rates, discounts, external billing, and aggregate-only CLI usage prevent
universal dollar-accurate reconstruction. Skill attribution remains a last-invoked
slash-command timeline convention, not provider-reported causal billing.
