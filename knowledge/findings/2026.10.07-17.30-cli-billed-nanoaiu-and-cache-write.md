# CLI Billing and Cache Writes

In `session.shutdown.modelMetrics[*].usage`, `inputTokens` equals fresh input
plus `cacheReadTokens` plus `cacheWriteTokens`. Example gpt-6-luna: 76736 =
12 + 51330 + 25394; with 749 output tokens the rate card gives USD 0.00406325,
exactly its `totalNanoAiu` of 406,325,000 (1 nanoAiu = 1e-11 USD).

Pricing tokens this way at the base tier reproduced per-model billed amounts
for 89 of 96 model entries. The earlier package estimate matched only 37: it
applied the cache-write premium to cache-write plus fresh tokens and selected
the long-context tier from the session-wide input sum, roughly doubling GPT
costs on long sessions. Remaining differences came from long-context requests,
discounts, or zero-token entries that aggregates cannot reveal.

Session-level `totalNanoAiu` is cumulative across resumes. `modelMetrics` and
`agentMetrics` carry state persisted by earlier shutdowns, but omit segments
that ended without a shutdown (for example, USD 0.0347 of a USD 0.1144 session). `agentMetrics` lists `main` and each subagent with its own billed
`totalNanoAiu`; their sum equals the per-model sum.

After using billed totals with an explicit unattributed remainder, all 101
sessions matched billed totals, and model and agent breakdowns reconciled.
