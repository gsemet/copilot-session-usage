  premium request units or tokens for usage-based billing and do not appear as
  billed line items.

The observed session contained eight `gpt-4o-mini-2024-07-18` background LLM
requests alongside the primary model requests. The model was present in the
local log and contributed to the analyzer's token totals and generic fallback
cost, but GitHub documents GPT-4o mini as a utility model that is not billed as
premium usage. Therefore, utility-model requests must be recognized by model
family and excluded from token totals, cost estimates, model and skill
breakdowns, subagent summaries, fallback-pricing reports, and commit-usage
trailers.

This finding is based on one VS Code session and GitHub's current utility-model
page. The utility-model list and naming/version patterns may change, so the
implementation should be reviewed when GitHub updates that documentation.
